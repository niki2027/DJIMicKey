# 验证范围

## 实体设备反馈

2026 年 11 月 7 日，使用者确认相机接收器兼容版本已在自己的 Windows 台式电脑上正常使用。已验证的连接组合是：

**大疆 Mini RS 麦克风发射器 → 无线 → 相机版接收器（USB `2CA3:4015`）→ C2C 数据线 → 台式电脑。**

这是一套实际设备与电脑环境的使用反馈，不能据此保证所有电脑、固件、应用或其他麦克风型号都兼容。上游 `2CA3:4011` 支持继续保留，本次未补充该旧设备的实体测试结论。

## 自动验证

相机接收器兼容实现已通过 [Windows 构建与测试](https://github.com/niki2027/DJIMicKey/actions/runs/42380215715)。正式发行版本的结果以对应标签关联的成功工作流为准。

- 识别检查覆盖 `4011`、`4015`、相似标识误匹配、非目标设备、Consumer 接口以及按键／音频就绪状态区分。
- 基础检查覆盖原生 ABI、快捷键与左右修饰键、设置、录制、Raw-only 与混合输入去重、畸形报告、暂停、设备移除及 Shell DLL 决策。
- `Test.cmd` 覆盖 DPI、放大文字、布局、托盘与退出、录制保存、诊断窗口生命周期和绘制反馈。
- 便携包检查要求配套 EXE、DLL、必要说明及 LICENSE 完整，两个二进制均为 Windows x64；不上传测试日志或个人诊断数据。

自动测试使用合成事件和隔离的临时设置，不等于真实发射器、无线链路或 ChatGPT 应用已经响应。无接收器时，`Test.cmd --device` 必须如实报告未就绪。

## 使用边界

- 本次验证面向 USB 数据连接；蓝牙直连、3.5 mm 音频连接、手机及其他型号未验证。
- 自定义快捷键需先在目标应用中用实体键盘验证。模拟输入可能受应用权限或应用自身支持范围影响。
- 正常 Raw Input 模式按目标设备筛选；初始化失败后的现有键盘回退可能接受其他来源的音量加键。
- Shell 音量增加抑制有全局范围，可能影响桌面上的其他音量加来源；暂停或完全退出后应恢复。
- 不修改 USB 驱动、固件或系统音量值，不保存或上传音频。
