# DJIMicKey v1.1.0 Windows 使用说明

运行环境为 Windows 10/11 x64 和 .NET Framework 4.8。最终用户不需要 GCC、AutoHotkey 或额外设备驱动。

## 连接与启动

已验证组合为大疆 Mini RS 麦克风与相机版接收器：发射器无线连接接收器，接收器通过 USB-C to USB-C（C2C）数据线连接 Windows 台式电脑。该接收器的 USB 标识为 `2CA3:4015`；同时保留 `2CA3:4011` 支持。

1. 从仓库 Releases 下载完整便携包，完全退出旧版，包括托盘实例。
2. 解压到独立文件夹，保持 `DJIMicKey.exe` 和 `DJIMicKey.Shell.dll` 同目录，再运行 EXE。
3. 接好 USB 数据线，确认发射器已配对、未静音。界面应显示实际接收器 ID；“接收器已识别”与音频接口就绪是两个状态。
4. 需要检查声音时，启动电平测试并对着麦克风说话。停止测试或隐藏窗口会释放音频采集，程序不保存或上传声音。

## 自定义按键映射

先用实体键盘确认目标应用的快捷键有效。点击“开始录制”，按下并松开目标单键或组合键，再点击“应用并保存”。组合键录制时先按住修饰键，再按下并松开主键，最后松开修饰键。Esc、超时或离开窗口会取消录制；保存失败时保留草稿及原设置。

设置完成后，短按发射器配对／连接键即可触发已保存的快捷键。默认组合为左 Ctrl + 左 Alt + F9，可自行更改；它不是经过通用验证的 ChatGPT 默认快捷键。目标应用必须支持对应操作，Windows `Win+H` 听写也不等于 ChatGPT 语音会话。

## 后台、暂停与回退

关闭窗口可选择退出或最小化到托盘。托盘继续映射并停止电平采集，双击托盘图标恢复窗口。首次使用建议先验证正常，再开启开机启动；移动程序后需重新设置启动路径。

暂停映射或完全退出会释放音量拦截。回退时先退出当前版本，再运行原版文件夹中的完整程序，不要混用不同版本的 EXE 与 DLL。

## 映射范围与本机排错

正常 Raw Input 模式只接受已支持接收器的 Consumer HID 来源，解析音量增加事件，并在松开后触发一次快捷键。若 Raw Input 初始化失败，现有键盘回退路径可能接受其他来源的音量加键；此时暂停映射并检查监听状态。

键盘与 Shell 音量增加抑制可能影响同桌面其他来源的音量加操作；不拦截音量减或静音，也不通过调整系统音量补偿。详情见 [SHELL_VOLUME_FILTER.md](SHELL_VOLUME_FILTER.md)。

按键无效时，可打开本机“诊断”，短按配对键三次，依次检查设备识别、Raw Input 接收、解码和快捷键发送。Windows 接受模拟输入不等于目标应用已经响应。诊断记录只留在本机，不提交到公开仓库或构建产物；不要公开个人路径、序列号、录音或设置文件。

设置保存在 `%LOCALAPPDATA%\DJIMicKey\settings.ini`。更详细的检查范围见 [VALIDATION.md](VALIDATION.md)。
